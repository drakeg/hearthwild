# Before the sprints: versions 0.1–0.10

Hearthwild was built for its first two weeks without a written process. This is a summary for the record; the full detail is in [`CHANGELOG.md`](../../../CHANGELOG.md).

| Version | Date | Theme |
|---|---|---|
| 0.1.0–0.3.0 | 2026-10-27 | First playable: the Stillwood, a server-authoritative world, combat, quests |
| 0.4.0–0.4.1 | late Oct | Accounts, equipment, desktop packaging; Starleaf gathering |
| 0.5.0 | late Oct | Trade, professions, wilderness, controls |
| 0.6.0–0.7.1 | late Oct | Classic MMO combat feel, realistic characters, hand-made world, food and drink |
| 0.8.0 | early Nov | Groups and the Hollow Crypt |
| 0.9.0 | early Nov | Guilds |
| 0.10.0–0.10.2 | early Nov | The Wider World (2 km, four zones); random loot; characters facing forward |

Releases for every OS have been published by GitHub Actions since 0.8.0.
